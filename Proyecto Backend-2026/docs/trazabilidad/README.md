# Evidencias de trazabilidad

Guardar aquí las capturas originales del procedimiento en el orden en que se toman. Usar nombres que relacionen cada imagen con el ISS, el paso y su secuencia:

`E-<ISS>-P<paso>-<secuencia>-<descripcion>.png`

Ejemplos para ISS-00:

- `E-ISS00-P01-01-version-node.png`
- `E-ISS00-P02-01-version-npm.png`
- `E-ISS00-P03-01-acceso-mysql.png`
- `E-ISS00-P04-01-verificacion-node-npm.png`

La descripción de cada captura y su relación con el paso deben quedar registradas en [`../Informe-Ejecucion.md`](../Informe-Ejecucion.md). No incluir secretos ni datos personales en las capturas.
